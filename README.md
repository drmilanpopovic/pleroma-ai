# Pleroma Ordinacija

Radni repozitorijum za novu Pleroma ordinaciju: PHP/SQLite, desktop i Android PWA.

Implementacija, dokumentacija i automatizovane provere stižu u razvojnoj grani. Softver je namenjen probnom radu i proveri instalacije pre stvarnih kliničkih podataka.

Ključevi, baze, korisničke sesije i dokumentacija pacijenata nisu deo izvornog koda.
